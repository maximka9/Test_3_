# Restaurant Booking System

Этот проект представляет собой систему для бронирования столиков в ресторане. Система позволяет создавать, удалять и проверять бронирования столиков для клиентов.

## Описание

Проект включает API для управления бронированиями столиков, а также функционал для:
- Создания и удаления столиков.
- Бронирования столиков на определённое время.
- Проверки наличия пересечений бронирований.

## Структура проекта

Проект состоит из следующих основных частей:
- **API для работы с бронированиями и столиками**.
- **Тесты** для проверки корректности работы системы.

### Структура файлов:
```
restaurant_booking/
├── app/
│   ├── __init__.py
│   ├── main.py              # Основной файл приложения
│   ├── models.py            # Модели данных (например, столики, бронирования)
│   └── services.py          # Логика работы с бронированиями
├── tests/
│   └── test_reservation.py  # Тесты для бронирований
├── docker-compose.yml       # Конфигурация для Docker Compose
└── requirements.txt         # Зависимости проекта
```

## Установка

Для установки и запуска проекта на локальной машине, выполните следующие шаги:

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/maximka9/Test_3_.git
   cd Test_3_
   ```

2. Создайте виртуальное окружение:
   ```bash
   python -m venv venv
   ```

3. Активируйте виртуальное окружение:
   - Для Windows:
     ```bash
     venv\Scripts\activate
     ```
   - Для Linux/macOS:
     ```bash
     source venv/bin/activate
     ```

4. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```

5. Для запуска проекта используйте Docker Compose:
   ```bash
   docker-compose up
   ```

   Это поднимет все необходимые сервисы: веб-сервер и базу данных.

## Запуск тестов

Для запуска тестов используйте следующую команду:

```bash
docker-compose exec web pytest
```

### Структура API

- **POST /tables/**: Создание нового столика.
  - Тело запроса:
    ```json
    {
      "name": "Столик 1",
      "seats": 4,
      "location": "зал"
    }
    ```

- **POST /reservations/**: Создание нового бронирования.
  - Тело запроса:
    ```json
    {
      "customer_name": "Иван",
      "table_id": 1,
      "reservation_time": "2025-04-14T19:00:00",
      "duration_minutes": 60
    }
    ```

- **DELETE /reservations/{id}**: Удаление бронирования.
  - Пример запроса:
    ```bash
    curl -X DELETE http://localhost:8000/reservations/1
    ```
